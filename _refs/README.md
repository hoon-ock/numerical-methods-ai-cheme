# Reference materials

Drop source material for the course in this folder:

- textbook PDFs (note which chapters matter — no need to read all 900 pages)
- existing course notebooks (`.ipynb`), scripts, or LaTeX notes
- syllabi, schedules, ABET outcome lists
- cloned repos of other Jupyter Book courses

**This folder is gitignored** (see `../.gitignore`). Copyrighted material stays
local and never enters git history. Only this README is tracked.

Suggested organization — not enforced:

```
_refs/
├── textbooks/
├── courses/        # cloned repos, other people's notebooks
├── syllabi/
└── papers/
```

For material that lives elsewhere on disk or on the web, there's no need to copy
it here — a path or URL is enough.
